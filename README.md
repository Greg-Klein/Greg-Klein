## Selected public work

- **[ai-rules-mcp](https://github.com/Greg-Klein/ai-rules-mcp)**: Dockerised MCP server that serves a team's AI skills and rules from a Git repo to Cursor, Claude Code, Cline and Windsurf.
- **[Apogée](https://apogee.gregoryklein.io)** ([code](https://github.com/Greg-Klein/apogee)): SpaceX flight activity dashboard on Launch Library 2. Never shows more than the source publishes: missing data is flagged, never faked.
- **[meteor_detector](https://github.com/Greg-Klein/meteor_detector)**: meteor detection pipeline on a Raspberry Pi 4: AllSky camera watcher, MQTT, Telegram alerts, nightly report, Next.js dashboard.
- **[meteor-ml-studio](https://github.com/Greg-Klein/meteor-ml-studio)**: local web UI to prepare, train, track and test YOLO meteor detection models.
